# TenObs
TENOBS Antivirus

Advanced Security. Simple Protection.

TENOBS is a Windows antivirus application designed to provide users with accessible security tools, file scanning, and threat detection through a modern and straightforward experience.

Our goal is to make system security simple, accessible, and efficient.

Overview

TENOBS is a standalone Windows application distributed through official executable releases.

No source code compilation, terminal commands, or development environment is required to run the application.

Users can simply download the latest .exe release and launch TENOBS on their Windows device.

Features
File Scanning — Analyze files for potential security threats.
Threat Detection — Identify potentially suspicious files.
Quick Scan — Perform fast security checks.
Custom Scan — Select specific files or directories to analyze.
Threat Management — Review detected suspicious files.
Quarantine — Isolate detected threats when supported.
Scan Reports — Review scanning results and activity.
User-Friendly Interface — Simple and accessible navigation.

Available features depend on the current release.
